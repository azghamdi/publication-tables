# صفحة الرقم القياسي لأسعار العقارات

صفحة تفاعلية لعرض جداول ورسومات الرقم القياسي لأسعار العقارات للربع الثاني من عام 2026.

## النشر على GitHub Pages

1. ارفع الملفين `index.html` و`README.md` إلى جذر المستودع.
2. من إعدادات المستودع افتح **Pages**.
3. اختر النشر من الفرع الرئيسي والمجلد الجذر `/ (root)`.
4. احفظ الإعدادات وانتظر ظهور رابط الصفحة.

## ملاحظات

- الصفحة والبيانات والرسومات ووظائف التنزيل موجودة داخل `index.html`.
- لا تحتاج الصفحة إلى خادم خلفي أو قاعدة بيانات.
- يلزم اتصال بالإنترنت لتحميل خط IBM Plex Sans Arabic من Google Fonts؛ وفي حال تعذّر ذلك تستخدم الصفحة الخطوط الاحتياطية تلقائيًا.
