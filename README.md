# صفحة الرقم القياسي لأسعار العقارات

صفحة تفاعلية لعرض جداول ورسومات الرقم القياسي لأسعار العقارات للربع الثاني من عام 2026.

## النشر على GitHub Pages

1. ارفع الملفات `index.html` و`README.md` و`ACCESSIBILITY-AUDIT.md` إلى جذر المستودع.
2. من إعدادات المستودع افتح **Pages**.
3. اختر النشر من الفرع الرئيسي والمجلد الجذر `/ (root)`.
4. احفظ الإعدادات وانتظر ظهور رابط الصفحة.

## ملاحظات

- الصفحة والبيانات والرسومات ووظائف التنزيل موجودة داخل `index.html`.
- يتضمن الملف `ACCESSIBILITY-AUDIT.md` نطاق مراجعة WCAG 2.2 AA والتحسينات وسيناريوهات الاعتماد اليدوي.
- لا تحتاج الصفحة إلى خادم خلفي أو قاعدة بيانات.
- الواجهة متجاوبة مع الجوال، وتشمل القوائم والفلاتر والتبويبات والجداول القابلة للتمرير والرسومات المكبرة.
- قسم المنهجية منظم في أكورديونات فرعية قابلة للفتح والإغلاق لتسهيل قراءة المحتوى الطويل.
- يتضمن تبويب «مقارنة البيانات» لمقارنة القطاعات وأنواع العقارات والمناطق بين فترتين، مع تنزيل Excel وPNG وSVG ورابط مشاركة.
- يلزم اتصال بالإنترنت لتحميل خط IBM Plex Sans Arabic من Google Fonts؛ وفي حال تعذّر ذلك تستخدم الصفحة الخطوط الاحتياطية تلقائيًا.
